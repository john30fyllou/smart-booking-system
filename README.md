# Smart Booking System

Το Smart Booking System είναι μια web εφαρμογή που ανέπτυξα στο πλαίσιο της πτυχιακής μου εργασίας.

Η βασική ιδέα της εφαρμογής είναι να διευκολύνει τη διαδικασία αναζήτησης και κράτησης υπηρεσιών. Υπάρχουν τρεις διαφορετικοί ρόλοι χρηστών: πελάτης, πάροχος υπηρεσιών και διαχειριστής.

Ένα από τα βασικά χαρακτηριστικά της εφαρμογής είναι η έξυπνη αναζήτηση. Ο χρήστης μπορεί να γράψει με φυσικό τρόπο τι υπηρεσία χρειάζεται και το σύστημα προσπαθεί να καταλάβει την πρόθεσή του και να του προτείνει την κατάλληλη διαθέσιμη υπηρεσία.

## Λειτουργίες

### Πελάτης

Ο πελάτης μπορεί να:

- δημιουργήσει λογαριασμό και να συνδεθεί
- δει τις διαθέσιμες υπηρεσίες
- αναζητήσει υπηρεσία χρησιμοποιώντας φυσική γλώσσα
- δει τις διαθέσιμες ημερομηνίες και ώρες ενός παρόχου
- πραγματοποιήσει κράτηση
- δει τα ενεργά και προηγούμενα ραντεβού του
- ακυρώσει ή να αλλάξει ένα ραντεβού

### Πάροχος

Ο πάροχος μπορεί να:

- δημιουργήσει λογαριασμό ως πάροχος
- αποκτήσει πρόσβαση μετά από έγκριση διαχειριστή
- δημιουργήσει και να διαχειριστεί τις υπηρεσίες που προσφέρει
- επιλέξει κατηγορία για κάθε υπηρεσία
- ορίσει τη διαθεσιμότητά του
- δει τις κρατήσεις των πελατών
- διαχειριστεί την κατάσταση των ραντεβού

### Διαχειριστής

Ο διαχειριστής μπορεί να:

- δει τους χρήστες του συστήματος
- εγκρίνει ή να απορρίψει νέους παρόχους
- διαχειριστεί τους ρόλους των χρηστών
- παρακολουθεί τις υπηρεσίες και τις κρατήσεις του συστήματος

## Έξυπνη αναζήτηση

Η εφαρμογή περιλαμβάνει λειτουργία αναγνώρισης πρόθεσης του χρήστη.

Για παράδειγμα, αντί ο πελάτης να πρέπει να γνωρίζει ακριβώς την κατηγορία ή το όνομα μιας υπηρεσίας, μπορεί να γράψει κάτι όπως:

> Θέλω να κάνω τα μαλλιά μου.

Το σύστημα αναλύει το αίτημα και προσπαθεί να το αντιστοιχίσει στην κατάλληλη κατηγορία και υπηρεσία, όπως για παράδειγμα μια υπηρεσία κομμωτικής.

Η λειτουργία αυτή αποτελεί και ένα από τα βασικά κομμάτια της πτυχιακής εργασίας.

## Τεχνολογίες

Για την ανάπτυξη της εφαρμογής χρησιμοποιήθηκαν:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- JWT για authentication
- bcrypt για την αποθήκευση των κωδικών πρόσβασης
- Git και GitHub

Το backend και η βάση δεδομένων έχουν γίνει deploy στο Railway, ενώ το frontend είναι διαθέσιμο μέσω GitHub Pages.

## Βάση δεδομένων

Η βάση δεδομένων περιλαμβάνει τους βασικούς πίνακες:

- users
- categories
- services
- bookings
- availability
- intent_logs

Μέσω αυτών αποθηκεύονται οι χρήστες, οι υπηρεσίες, οι κατηγορίες, οι κρατήσεις, η διαθεσιμότητα των παρόχων και τα αποτελέσματα της έξυπνης αναζήτησης.

## Σκοπός

Στόχος της εργασίας είναι να δημιουργηθεί ένα λειτουργικό σύστημα κρατήσεων και παράλληλα να εξεταστεί πώς μπορεί η αναγνώριση πρόθεσης από φυσική γλώσσα να κάνει την αναζήτηση υπηρεσιών πιο απλή για τον χρήστη.

Το project αναπτύχθηκε σταδιακά, από τη δημιουργία της βάσης δεδομένων και του backend μέχρι τα dashboards των χρηστών, το σύστημα κρατήσεων και την τελική online έκδοση.
