# Smart Booking System

Το Smart Booking System είναι μια web εφαρμογή διαχείρισης υπηρεσιών και ραντεβού, η οποία αναπτύχθηκε στο πλαίσιο της πτυχιακής μου εργασίας.

Στόχος της εφαρμογής είναι να διευκολύνει την επικοινωνία μεταξύ πελατών και παρόχων υπηρεσιών, προσφέροντας ένα ενιαίο σύστημα για αναζήτηση υπηρεσιών, κρατήσεις και διαχείριση ραντεβού.

## Βασικές λειτουργίες

Η εφαρμογή υποστηρίζει τρεις διαφορετικούς ρόλους χρηστών:

- **Πελάτης:** μπορεί να αναζητήσει διαθέσιμες υπηρεσίες, να πραγματοποιήσει κράτηση και να διαχειριστεί τα ραντεβού του.
- **Πάροχος:** μπορεί να δημιουργήσει και να διαχειριστεί τις υπηρεσίες που προσφέρει, καθώς και τη διαθεσιμότητά του.
- **Διαχειριστής:** μπορεί να διαχειρίζεται τους χρήστες του συστήματος και να εγκρίνει ή να απορρίπτει νέους παρόχους.

Επιπλέον, υπάρχει λειτουργία έξυπνης αναζήτησης, μέσω της οποίας ο χρήστης μπορεί να περιγράψει με φυσική γλώσσα την υπηρεσία που χρειάζεται και το σύστημα να προτείνει την καταλληλότερη διαθέσιμη υπηρεσία.

## Τεχνολογίες

Για την ανάπτυξη του συστήματος χρησιμοποιήθηκαν:

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL
- bcrypt
- JWT (JSON Web Tokens)

## Ασφάλεια

Οι κωδικοί των χρηστών δεν αποθηκεύονται σε απλή μορφή στη βάση δεδομένων. Για την ασφαλή αποθήκευσή τους χρησιμοποιείται το `bcrypt`, ενώ για την αυθεντικοποίηση και τον έλεγχο πρόσβασης χρησιμοποιούνται JSON Web Tokens.

Το σύστημα διαθέτει επίσης διαφορετικά δικαιώματα πρόσβασης ανάλογα με τον ρόλο του χρήστη.

## Βάση δεδομένων

Η εφαρμογή χρησιμοποιεί σχεσιακή βάση δεδομένων MySQL για την αποθήκευση των χρηστών, των κατηγοριών, των υπηρεσιών, της διαθεσιμότητας και των κρατήσεων.

## Deployment

Το backend και η βάση δεδομένων έχουν αναπτυχθεί σε περιβάλλον cloud μέσω Railway.

Το frontend φιλοξενείται μέσω GitHub Pages και επικοινωνεί με το backend μέσω REST API.

## Κατάσταση έργου

Το σύστημα βρίσκεται σε λειτουργική έκδοση και υποστηρίζει την πλήρη βασική ροή:

Εγγραφή χρήστη → Σύνδεση → Έγκριση παρόχου → Δημιουργία υπηρεσίας → Διαθεσιμότητα → Αναζήτηση υπηρεσίας → Κράτηση → Διαχείριση ραντεβού.
